# KULT — Cinematic Digital Identity

Personal site for KULT (Tashkent, Uzbekistan): a single cinematic scroll through five scenes
built with React, Vite, React Three Fiber, GSAP ScrollTrigger and Tailwind CSS.

```bash
npm install
npm run dev      # local development
npm run build    # production build in dist/
```

- `src/content.js` — all text, gallery projects, social links and contact (placeholders until filled in)
- `src/lib/director.js` — per-section camera and sculpture keyframes
- `src/three/` — procedural liquid-metal sculpture, fog, particles, post effects
- `src/sections/`, `src/components/` — page sections and reusable UI
